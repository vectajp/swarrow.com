
# Swarrow　Call

AI カスタマーサポートサービス「Swarrow Call」のランディングページ。

元デザイン: https://www.figma.com/design/2eT31sLxtnkjkDpM1l1CMI/SwarrowCall

## セットアップ

[mise](https://mise.jdx.dev/) を使用する場合:

```sh
mise run bootstrap
```

手動の場合:

```sh
bun install
```

## 開発

```sh
bun run dev    # 開発サーバー起動
bun run build  # ビルド
```

## ドキュメント

- [Pages Functions](docs/pages-functions.md) -- 旧 endpoint と資料請求 API 連携設定
